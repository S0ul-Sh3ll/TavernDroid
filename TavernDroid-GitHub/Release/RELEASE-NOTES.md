# TavernDroid 1.0.0

The full **SillyTavern 1.19.0** as a native Android app. No Termux, no PC, no command line.

## Highlights
- Every SillyTavern feature: all APIs, characters (PNG/JSON/CharX), groups, World Info, STscript, Quick Replies,
  extensions (installed with the bundled git), TTS, image generation, on-device embeddings, themes, multi-user
- 🔐 6-digit PIN lock with auto-lock (default 5 minutes)
- 🔋 Replies keep generating with the screen off, with a notification when they arrive
- 📥 Exports to `Downloads/SillyTavern`, imports through the file picker, Back closes panels first
- 🗣️ System TTS with your phone's voices
- 📶 Optional LAN mode to use the phone as a server for other devices
- 💾 One-tap backup/restore and import of a Termux or PC `data` folder
- 🧠 Tokenizers bundled, so token counting works offline
- 🩹 Automatic server restart if Android kills it for memory

## Install
Android 7.0+ on 64-bit ARM. Download `TavernDroid-1.0.0.apk` below, allow installing from your browser/files app,
open it, create your PIN, and connect your AI in the 🔌 panel.
